Materials and Methods


  

    
Genome Data and Preprocessing

    

      
Genome assemblies and predicted protein sequences for 26 Dendrobium species were used as input for all downstream analyses. For species where multiple independent genome assemblies were publicly available (namely D. catenatum, D. nobile, D. secundum, D. thyrsiflorum, D. lindleyi, and D. chrysotoxum), the assembly whose gene identifiers were consistent with the pangenome reference used in this study was selected; NCBI RefSeq annotations carrying gene ID prefixes (KAI, KAH, PKU) derived from alternative assemblies were excluded to ensure cross-species identifier consistency. Protein sequences were filtered to retain only the primary isoform per locus (longest CDS-supported isoform) using a custom Python script prior to ortholog inference.

    

  


  

    
Pangenome Construction and Phylogenetic Analysis

    

      
Ortholog Inference

      
Orthologous gene groups (orthogroups) across all 26 species were identified using OrthoFinder v2.5.5. All-versus-all protein sequence similarity searches were performed using Diamond v2.1.12 with default OrthoFinder parameters. Orthologous clustering was performed using the Markov Cluster Algorithm (MCL) with an inflation parameter of 1.5. OrthoFinder was executed with 32 threads for sequence search (-t 32) and 8 threads for analysis (-a 8):

      
orthofinder -f pep_cleaned/ -t 32 -a 8 -o orthofinder_results/


      
Pangenome Gene Classification

      
Orthogroups were classified into four categories based on their presence across the 26 species:

      
    
        
  • Core genome: orthogroups present in all 26 species (100%)
    • 
        
  • Softcore genome: orthogroups present in ≥ 24 species (≥ 94%)
    • 
        
  • Dispensable genome: orthogroups present in 2–23 species
    • 
        
  • Private genome: orthogroups unique to a single species
    • 
      


      
Species Phylogeny

      
A rooted species phylogeny was inferred from the OrthoFinder results using the STAG (Species Tree from All Genes) method. Individual gene trees were constructed using FastTree for each of the 322 single-copy orthogroups. The consensus species tree was rooted using the STRIDE algorithm and visualised using the ETE3 toolkit.

    

  


  

    
Synteny Analysis

    

      
Whole-Genome Pairwise Alignment

      
Chromosome-level synteny was assessed for all C(26, 2) = 325 pairwise combinations using minimap2 v2.28:

      
minimap2 -c -x asm5 -t 4 {target.fa} {query.fa} > {output.paf}


      
Gene-Level Collinearity

      
Syntenic gene blocks were identified for all 325 species pairs using JCVI v1.5.11. Protein sequences were compared using Diamond v2.1.12 in BLASTp mode (E-value ≤ 1×10⁻⁵), then syntenic blocks were detected with:

      
python -m jcvi.compara.synteny scan \
    {sp1.sp2.blast} {sp1.sp2.anchors} \
    --qbed {sp1.bed} --sbed {sp2.bed} \
    --no_strip_names --dist=20 --min_size=4

      
Parameters: --dist=20 (maximum rank-distance between collinear pairs), --min_size=4 (minimum anchor pairs per block).


      
Synonymous Substitution Rate (Ks) and Ka/Ks Estimation

      
For each of the 325 species pairs, up to 200 syntenic gene pairs were randomly sampled from the JCVI .anchors file. Gene pairs were pre-filtered to include only those where both CDS were between 300 and 3,000 bp. Ks and Ka values were estimated using a three-step pipeline:

      
    
        
  1. Protein alignment with MAFFT v7.525 (--auto --quiet)
    2. 
        
  2. Protein-to-codon alignment conversion with PAL2NAL (-output paml -nogap)
    3. 
        
  3. Ka/Ks estimation with yn00 from PAML v4.9j (Yang & Nielsen 2000 ML method; icode=0, standard genetic code)
    4. 
      

      
Median Ks values per species pair were used to construct the 26×26 pairwise Ks matrix.

    

  


  

    
Structural Variant Detection

    

      
Inter-species structural variants (SVs) were identified for all 325 species pairs using SyRI v1.x. Analysis was performed on a per-chromosome basis, restricted to chromosomes ≥ 5 Mbp, matched by rank order. Per-chromosome pairwise alignment was performed using nucmer from MUMmer4:

      
nucmer -c 500 -b 500 -l 100 --prefix {prefix} {ref.fa} {qry.fa}
delta-filter -m -i 90 -l 100 {input.delta} > {filtered.delta}
syri -c {coords} -d {filtered.delta} -r {ref.fa} -q {qry.fa} --nc 2 --all --log WARN

      
For 298 of 325 species pairs, a minimum alignment identity of 90% was applied. The remaining 27 pairs — predominantly involving D. parcum, D. spatella, D. secundum, and D. ChaoPraya Smile — failed to yield SV calls even at a relaxed threshold of 70%, reflecting genuine large-scale sequence divergence. Structural variant analysis was successfully completed for 298 of 325 species pairs (91.7%). Per-chromosome SyRI VCF outputs were merged, compressed with bgzip, and indexed with tabix for genome browser integration.

    

  


  

    
Functional Annotation

    

      
Functional annotations were assigned to the predicted protein sequences of all 26 species using eggNOG-mapper v2.1.13 against the eggNOG v5.0.2 database, with Diamond v2.1.12 as the sequence search engine. The following annotation categories were extracted and summarised per species:

      
    
        
  • COG functional categories (Clusters of Orthologous Groups)
    • 
        
  • Gene Ontology (GO) terms
    • 
        
  • KEGG Orthology (KO) identifiers and metabolic pathway assignments
    • 
        
  • Pfam domain identifiers
    • 
        
  • Enzyme Commission (EC) numbers
    • 
      

      
For comparative visualisation, the 30 most abundant KEGG pathways and 25 most abundant Pfam domains aggregated across all 26 species were selected.

    

  


  

    
Sequence Similarity Search (BLAST)

    

      
An interactive BLAST search interface is provided to query user-supplied sequences against the predicted protein and CDS databases of all 26 Dendrobium species. Custom BLAST databases were constructed using BLAST+ v2.x makeblastdb from the protein (*.pep.fa) and coding sequence (*.cds.fa) files of all 26 species. Each sequence header was prefixed with a species identifier ({sp_id}|{gene_id}) to enable per-species hit attribution. Non-standard residues (., -) were converted to X prior to database construction; sequences shorter than 10 residues were excluded. The combined databases contain 737,041 protein sequences and 737,041 CDS sequences.

      
Protein queries are searched using blastp; nucleotide queries are searched using blastn against the CDS database. Query type is auto-detected from sequence composition (nucleotide ratio >90% → blastn). Users may restrict the search to any subset of the 26 species. For each species, only the single best-scoring HSP per subject sequence is reported. The search is executed server-side via a Flask/Gunicorn API co-hosted with the dashboard on the same port.
